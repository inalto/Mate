# What is new in Mate 1.1.0

## Dictated maths

- Say an equation and Mate writes it as notation. "y equals x plus ten" becomes `y = x + 10` in an equation box on the page. English, Italian, French, Spanish, German and Portuguese are understood: "y uguale x più dieci", "y égale x plus dix", "y es igual a x más diez", "y gleich x plus zehn", "y é igual a x mais dez".
- Fractions ("tutto fratto", "all over"), powers, roots and number words are understood. When the result is not a valid expression, or you are dictating into a text box, the words stay as text (inside a text box the notation is added as text). Ordinary sentences are never rewritten.
- Turn it off with **Convert spoken maths to notation** under Settings, Dictation.
- New, off by default: **Tidy dictation with the AI assistant** fixes punctuation and writes maths with LaTeX. It needs the AI assistant to be set up with your consent and key. Only the transcribed text is sent to your AI provider, never the audio.
- Mate also tells the speech service which language and style to expect, so equations are transcribed more reliably.

## Lasso

- Draw the loop clockwise to select what is inside it, as before. Draw it **anticlockwise** to select everything the loop touches: a stroke it crosses, a box it passes through, or an image it is drawn inside.
- In touch mode the outline is dashed.

## Swipe to turn pages

- On a touch screen, a quick one-finger swipe sideways turns the page when the edge of the sheet is already in view. Swipe left for the next page: on the last page it adds a new one at the end of the section. Swipe right for the previous page.
- It works on pages only, never on the infinite canvas, and has no setting.

## Fixes

- Integrals written with an upright **dx** now work in the graph panel and the maths panel.

# What is new in Mate 0.9.0

## Library folders

- Books can now live in folders, and folders can hold other folders. The library shows a path at the top, the subfolders and the books of the folder you are in, with **New folder** to add one there.
- **Move to...** on a book or a folder lets you pick where it goes. A folder cannot be moved into itself or into one of its own subfolders.
- Deleting a folder sends it and its subfolders to the trash. The books inside are not deleted: they become unfiled.
- Your existing shelves are now top-level folders.

## Graph presets

- A graph can save its settings (kind, range, grid and so on, and the expressions if you want) as a named preset.
- Presets are kept per graph kind, and you can mark one preset per kind as the default. New graphs start from the default of the kind you used last.
- Rename or delete presets under Settings → Graphs.

## Run code

- Code blocks in JavaScript, TypeScript and Python have a **Run** button (Ctrl/Cmd+Enter while editing). The output shows under the code and is saved with it, up to the last 200 lines.
- A run stops after 10 seconds. **Stop**, **Clear output** and **Reset runtime** are in the code toolbar.
- Each language keeps its variables between runs on a page, until you reset the runtime. In JavaScript, top-level `let` and `const` carry over too.
- Python runs with Pyodide, which is bundled with the app (about 14 MB) and loads the first time you run Python. Only the Python standard library is available.
- Code runs on your device in a background worker, with no network access.

## Known limitations

- Output appears when the run ends, not while it runs.
- Python on Android has not been tried on a device yet, and it needs a fairly recent System WebView.
- The new text is translated in English and Italian only; the other languages show English for now.

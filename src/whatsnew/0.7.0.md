# What is new in Mate 0.7.0

## Android tablets

- Mate now runs on Android tablets. It installs on Android 7.0 and later but has been tested on Android 16 only (on the emulator); older versions are untested, and the Android System WebView must be reasonably current. Each release has a signed APK for 64-bit ARM tablets; install it by sideloading.
- The same library, ink canvas, typed maths, graphs, PDFs, tutor and maths engines as on the desktop.
- Pages open in place, the toolbar and sidebar are laid out for a tablet, and your notes are saved as soon as Mate goes to the background.
- Open and Import use the system file picker, and every export (PNG, SVG, PDF, LaTeX, `.mate`) goes out through the Android share sheet.

## Known limitations on Android

- Opened files are titled by an internal document id, not their file name; rename them after opening.
- The Files app does not offer Mate for `.mate` files yet, and "Share to Mate" is not supported. Use Open or Import inside Mate.
- AI and maths-engine keys are kept in a file in the app's private storage, not in the Android Keystore.
- There is no in-app updater on Android: install the next APK over this one.
- So far Mate is tested on the Android 16 emulator, not yet on real tablets with a pen or on older Android versions.
- Opening a file that is too large (over 200 MiB) or unreadable shows nothing.

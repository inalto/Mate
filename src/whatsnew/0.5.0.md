# What is new in Mate 0.5

## Welcome

- A short welcome on first launch, with optional AI setup and a Playground page to try the pen.
- Show the welcome again from Settings, About.
- A What's new notice appears once after each update.

## Settings

- The settings pane has a list of sections on the left and a search box at the top.
- Download a backup of every book in one zip file, with one .mate file per book to import again.
- Reset local data writes a recovery zip before anything is deleted. API keys in the system keychain are kept.

## Keyboard shortcuts

- Change, unbind or reset shortcuts in Settings, Keyboard shortcuts. Keys that clash with another shortcut are flagged. The pen preset slots, Space to pan and Esc are fixed.
- Press ? to see every shortcut.
- Press Ctrl+K to search pages and run actions. Recent pages appear first.
- Shortcut hints on toolbar buttons can be always on, shown until you have learned them, or off.

## Windows

- Open any page in its own window from the sidebar menu, or press Ctrl+Shift+N.
- Each page opens in at most one extra window. Opening it again brings that window forward.
- A page window closes when its page is moved to the trash.
- Closing the main window closes page windows first, saving their work as it goes.

## Pen

- Pen haptics on Windows: a buzz while you ink and a click when a shape snaps. Turn it on or off in Settings, Pen and stylus. It has not yet been tested on every pen, so tell us if it does not behave.
- Snap to grid and a zoom level indicator are available as options.

## Updates

- Check for updates from Settings, Updates, or let Mate check when it starts.
- Mate saves your work before it installs an update. Windows restarts into the new version by itself. On macOS and Linux you choose when to restart.
- Builds without a signing key say that updates are not configured.

## Fixes

- Dialogs and menus close with Escape, and most shortcuts no longer work behind an open dialog.
- The Close anyway notice goes away on its own after 30 seconds.
- Import messages say which limit was reached and show large numbers with separators.
- Only the ten newest recovery files are kept.

Your notes stay on this device.
